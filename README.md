# Smart Attendance System Using Deep Learning

## Project Description
This project is a web-based student attendance management system that uses deep learning-based face recognition to mark attendance.

## Technologies Used
- Python
- Flask
- DeepFace and FaceNet
- OpenCV
- HTML, CSS and JavaScript
- SQLite

## Features
- Student registration with face image
- Face recognition-based attendance marking
- OD letter submission
- Attendance report viewing
- Student attendance management

## How to Run
1. Install Python and the required libraries.
2. Open the project folder in VS Code.
3. Run `py -3.12 app.py` in the terminal.
4. Open `http://127.0.0.1:5000` in your browser.
